# Jenteck Jailbreak Manager

A rootless semi-untethered jailbreak manager for iOS 15.0 – 15.8.8 (arm64), part of the [Jenteck](https://jenteck.co.uk) ecosystem.

Built on top of [Dopamine](https://github.com/opa334/Dopamine) by Lars Fröder (opa334) — see `LICENSE.md` and the in-app Credits screen for full upstream attribution (Dopamine, kfd, weightBufs, libgrabkernel2, ElleKit, Fugu15, Procursus, Sileo, ChOma, XPF, opainject, libc, Zebra, plooshinit).

Please note that all issues related to version support will be deleted without response.
